# Workflow router

Choose the smallest workflow that fits.

| Task | Workflow |
|---|---|
| One bounded bug or small change | `small-fix.md` |
| Normal product feature | `product-feature.md` |
| High-risk/release work | `release.md` |
| Persuasive copy | `../skills/copywriting/SKILL.md` |
| SEO | SEO Specialist -> builder if code is required -> Reality Checker |
| Tracking | Tracking Specialist -> builder if code is required -> Reality Checker |

## Do not over-orchestrate

A five-minute fix does not need a product brief, architecture review, six agents, and a video recording.

A pricing migration, auth change, data migration, or production release may need deeper controls.

Risk and reversibility determine workflow depth.
