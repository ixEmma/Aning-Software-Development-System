# Human technical writing

Use for technical prose people will read.

## Goal

Make the writing sound like a competent person explaining concrete work, not an AI narrating itself.

## Edit rules

- Lead with the actual change or fact.
- Prefer plain words.
- Remove filler, puffery, generic conclusions, and chatbot phrases.
- Avoid repeating the same point under multiple headings.
- Prefer active voice when the actor matters.
- Split sentences that require rereading.
- Use technical jargon only when it is the precise term.
- Replace vague claims with measured facts when available.
- Do not manufacture confidence, metrics, or outcomes.
- Keep commit messages and PR text proportional to the change.

## Boundaries

Do not use this skill as the marketing-copy framework.

Persuasive sales/marketing work routes through `../copywriting/SKILL.md`.
